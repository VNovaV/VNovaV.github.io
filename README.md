# VNovaV.github.io

个人作品集站点（3D 角色建模方向），由 GitHub Pages 自动托管：

👉 https://VNovaV.github.io

## 这是什么

这是一个**自带编辑器的作品集单页应用**：

- 点格子上传图片（或拖拽），自动存入浏览器本地（IndexedDB）
- 文字均可双击/直接编辑（作品名、章节、图片说明等）
- 右上角可切换 4 套配色：纸白 / 墨黑 / 暖米 / 深蓝
- 滚动有入场动画与图片视差效果
- 内容自动保存在本地，刷新不丢

## 本地预览

直接用浏览器打开 `index.html` 即可；或在本目录运行：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
.
└── index.html      # 作品集应用（HTML + 内联样式 + JS，自包含）
```

> 提示：图片保存在访问者浏览器的 IndexedDB 中。若要在多设备保持同一份内容，
> 需在同一浏览器里编辑；如需把成品导出成静态图片页，可在此基础上再做导出功能。
